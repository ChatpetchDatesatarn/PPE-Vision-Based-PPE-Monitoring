1. ปัญหาหรือความท้าทายที่ต้องการแก้ไข (Problem Statement)
การไม่สวมอุปกรณ์ป้องกันส่วนบุคคล (PPE) เช่น หมวกนิรภัยและเสื้อสะท้อนแสง รวมถึงการเข้าเขตอันตราย เป็นสถานการณ์เสี่ยงที่ต้องเฝ้าระวังในโรงงานอุตสาหกรรม การตรวจสอบโดยเจ้าหน้าที่เพียงอย่างเดียวอาจไม่ครอบคลุมทุกพื้นที่และทุกช่วงเวลา ทีมจึงต้องการพัฒนาเครื่องมือช่วยตรวจพบและแจ้งเตือนสถานการณ์เสี่ยง เพื่อให้เจ้าหน้าที่รับรู้และตรวจสอบได้รวดเร็วขึ้น

2. แนวทางการแก้ไขหรือรูปแบบโซลูชันที่นำเสนอ (Proposed Solution)
พัฒนาระบบวิเคราะห์ภาพจากกล้องด้วย AI เพื่อตรวจจับบุคคลและการสวมหมวกนิรภัยหรือเสื้อสะท้อนแสง พร้อมให้ผู้ดูแลกำหนดเขตเฝ้าระวังเสมือน (Virtual Safety Zone) บนภาพ และตั้งเงื่อนไขการแจ้งเตือนให้เหมาะกับพื้นที่
เมื่อพบการไม่สวม PPE หรือมีบุคคลเข้าเขตที่กำหนด ระบบจะตรวจสอบเหตุการณ์ต่อเนื่องตามเงื่อนไขก่อนแจ้งเตือนผ่าน Dashboard และอุปกรณ์ไฟหรือเสียงเตือน เพื่อลดการแจ้งเตือนจากภาพชั่วขณะ หากภาพไม่ชัดหรือถูกบดบัง ระบบจะแสดงสถานะตรวจสอบไม่ได้แทนการสรุปว่าไม่สวมอุปกรณ์ เจ้าหน้าที่สามารถตรวจยืนยันเหตุการณ์และบันทึกผลการดำเนินการย้อนหลังได้

3. ประโยชน์หรือผลลัพธ์ที่คาดว่าจะได้รับ (Expected Benefits)
มุ่งช่วยลดความเสี่ยงจากการไม่สวม PPE และการเข้าพื้นที่อันตราย เพิ่มความครอบคลุมในการเฝ้าระวัง และสนับสนุนการทำงานของเจ้าหน้าที่ความปลอดภัย พร้อมรวบรวมข้อมูลเหตุการณ์เพื่อใช้ทบทวนจุดเสี่ยงและปรับปรุงมาตรการภายในโรงงาน
ทีมจะประเมินต้นแบบจากความแม่นยำในการตรวจจับ อัตราการแจ้งเตือนผิด เหตุการณ์ที่ตรวจไม่พบ และระยะเวลาตั้งแต่เกิดเหตุจนแจ้งเตือน โดยยังไม่กล่าวอ้างผลการลดอุบัติเหตุจนกว่าจะมีการทดสอบใช้งานจริงรองรับ

4. เทคโนโลยี AI หรือเทคโนโลยีที่เกี่ยวข้องที่คาดว่าจะนำมาใช้ (AI Technologies to be Used)
ใช้ Computer Vision และ Object Detection เพื่อตรวจจับบุคคล หมวกนิรภัย และเสื้อสะท้อนแสง ร่วมกับการติดตามวัตถุระหว่างเฟรม (Object Tracking) และการจับคู่ PPE กับบุคคล เพื่อประเมินสถานะการสวมอุปกรณ์อย่างต่อเนื่อง ใช้ตำแหน่งบุคคลร่วมกับกฎเชิงพื้นที่เพื่อตรวจการเข้า Virtual Safety Zone
ประมวลผลภาพบนคอมพิวเตอร์หรือ Edge AI Device และเชื่อมต่อระบบแจ้งเตือนผ่าน MQTT โดยใช้ ESP32 หรือ STM32 ควบคุมไฟ Warning Light และ Buzzer พร้อมเว็บ Dashboard สำหรับแสดงสถานะ ตั้งค่าเขตเฝ้าระวัง และตรวจสอบประวัติเหตุการณ์ ทั้งนี้จะเลือกโมเดลและอุปกรณ์จากผลทดสอบความแม่นยำ ความเร็ว และต้นทุนของต้นแบบ

5. ข้อมูลหรือรายละเอียดเพิ่มเติม (Additional Information)
ต้นแบบจะเริ่มจากกล้อง IP Camera หรือ Webcam จำนวนหนึ่งตัว ในพื้นที่สาธิตหนึ่งจุด โดยตรวจ PPE สองประเภท ได้แก่ หมวกนิรภัยและเสื้อสะท้อนแสง รวมถึงการเข้าเขตที่กำหนด ทดสอบภายใต้สภาพแสง มุมกล้อง และการบดบังที่แตกต่างกัน โดยไม่ให้ผู้เข้าร่วมเข้าไปในพื้นที่อันตรายจริง
การทดสอบจะใช้ผู้เข้าร่วมที่รับทราบและยินยอม ไม่ใช้การจดจำใบหน้า และกำหนดสิทธิ์เข้าถึงกับระยะเวลาเก็บภาพเหตุการณ์ ระบบมีบทบาทช่วยเฝ้าระวังและสนับสนุนการตัดสินใจของเจ้าหน้าที่ ไม่ใช้แทนมาตรการป้องกัน ระบบหยุดเครื่องจักรฉุกเฉิน หรือการตรวจสอบความปลอดภัยโดยผู้รับผิดชอบ
