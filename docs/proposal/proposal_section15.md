# Proposal — ข้อ 15 (บันทึกจากผู้ใช้ 2026-10-28)

> ฉบับย่อที่ผู้ใช้ให้มาเพื่อตั้งวัตถุประสงค์/เกณฑ์ (บท 1, 6.5). ฉบับเต็มทางการ = `docs/proposal.txt`.

**Problem Statement:** ในโรงงานอุตสาหกรรม พนักงานอาจลืมหรือไม่ปฏิบัติตามข้อกำหนดด้านความปลอดภัย เช่น ไม่สวมหมวกนิรภัยหรือเสื้อสะท้อนแสง รวมถึงอาจเข้าไปในพื้นที่อันตรายโดยไม่ได้รับอนุญาต การตรวจสอบโดยเจ้าหน้าที่ตลอดเวลาทำได้ยากและอาจเกิดความผิดพลาดจากมนุษย์

**Proposed Solution:** พัฒนาระบบ AI Smart Safety Monitoring โดยใช้กล้องร่วมกับ Computer Vision เพื่อตรวจจับบุคคลและอุปกรณ์ PPE แบบ Real-time เช่น หมวกนิรภัยและเสื้อสะท้อนแสง พร้อมกำหนด Virtual Safety Zone บนภาพจากกล้อง หากตรวจพบพนักงานที่ไม่สวม PPE หรือเข้าไปในพื้นที่อันตราย ระบบจะแจ้งเตือนทันทีผ่านไฟสัญญาณ เสียงเตือน และ Dashboard ของผู้ดูแล

**Expected Benefits:** ช่วยลดความเสี่ยงในการเกิดอุบัติเหตุ เพิ่มประสิทธิภาพในการตรวจสอบความปลอดภัย ลดภาระของเจ้าหน้าที่ Safety และสามารถเก็บข้อมูลเหตุการณ์เพื่อนำไปวิเคราะห์และปรับปรุงมาตรการความปลอดภัยภายในโรงงาน

**AI Technologies to be Used:** ใช้ Computer Vision และ Object Detection สำหรับตรวจจับบุคคล หมวกนิรภัย และเสื้อสะท้อนแสง รวมถึงใช้ AI วิเคราะห์การเข้าเขตพื้นที่อันตรายแบบ Real-time และสามารถพัฒนาต่อยอดไปสู่การตรวจจับพฤติกรรมหรือเหตุการณ์ผิดปกติได้

**Additional Information:** ต้นแบบสามารถใช้กล้อง IP Camera/Webcam เชื่อมต่อกับ Edge AI Device หรือ Computer สำหรับประมวลผลภาพ และเชื่อมต่อ ESP32/STM32 เพื่อควบคุมไฟ Warning Light, Buzzer หรืออุปกรณ์แจ้งเตือน โดยส่งข้อมูลเหตุการณ์เข้าสู่ IoT Dashboard ผ่าน MQTT เพื่อแสดงสถานะและประวัติการแจ้งเตือน

---
**หมายเหตุขอบเขตจริง (2026-10-28):** ESP32/STM32 + ไฟ/Buzzer **ตัดออกจากขอบเขตต้นแบบ** (ผู้ใช้ยืนยัน) — แจ้งเตือนผ่าน Dashboard แทน (ไฟสถานะ + รายการเหตุการณ์ + เสียง beep). อุปกรณ์ไฟ/เสียงหน้างานทำต่อยอดได้ผ่าน MQTT topic `factory/safety/cam01/event` เดิม = ทางเลือก ไม่ใช่งานค้าง.
