## 1. Camera (Tapo C200C probe)
| Item | Result |
|---|---|
| Network | ping 0 % loss, rtt avg 10 ms (Wi-Fi 2.4 GHz) |
| Streams | stream1 1920×1080, stream2 1280×720, both H.264 High + PCMA audio |
| Decode fps, camera set to 30 fps (TCP, NVDEC) | stream1 **29.25**, stream2 only **19.12** (17–20) |
| Camera unplugged | no ERROR; **EOS after 25 s** (rtspsrc `tcp-timeout` 20 s default); pipeline does not recover by itself |
| Camera boot | first video, drop again for ~13 s, stable 22 s after first sign |
| Values chosen | TCP, latency 200, drop-on-latency, video only (`select-stream`), watchdog 3 s, `tcp-timeout` 5 s, handle EOS + ERROR, reconnect every 2 s for 60 s then 5 s (max 10 s), `camera_connected=true` after 10 s of frames |

## 4. PPE 3-class model (person, helmet, vest)
| Item | Result |
|---|---|
| Training (Colab A100, 416) | yolov8n_ppe3 test mAP50 **0.876** (person 0.932, helmet 0.816, vest 0.880), best_conf 0.52; yolo11n_ppe3 0.882 (tie) |
| Engine on Jetson (file source) | yolov8n_ppe3 **47.97 fps** at `interval=0` (+9 % vs COCO), 96.65 at `interval=1`; yolo11n_ppe3 45.45 / 90.42 → **yolov8n_ppe3 chosen** |
| In the app with the camera (P1–P3) | **29.1 fps** (camera rate), cpu mean 52–58 %, GR3D mean ~57 %, RAM max ~2040 MB, °C max 47.5, 0 camera drops |
| P2: confidence labels | `P1 0.87 H✓ V✗`, `H 0.72`, `V 0.65`; conf mean/min per class every 5 s in the log |
| P3: per-class threshold | person 0.30, helmet 0.40, vest 0.35 (was 0.52 for all); nvinfer uses them (P3 minimums 0.301 / 0.402 / 0.350) |
| P3: hold | hidden person keeps the last box for 0.6 s (`P1 -- H✓ V✗`) |
| P3: `PpeSmoother` | H/V from the last 20 frames of each person: ✓ ≥ 30 %, ✗ < 10 %, keep in between, `?` before 8 frames; 10 tests pass on the PC and the Jetson |
| Problems on the real camera | (a) people who sit, bend down or are behind a desk are missed (P2: conf 0.52–0.77 then lost); (b) a knitted beanie is detected as a helmet (conf 0.76); (c) overlay covered the Tapo date / time → **fixed** (moved down 40 px; compiles, not run yet) |
| Conclusion | app + `PpeSmoother` are ready to keep using; PPE results wait for the next ppe3 model trained with real Tapo frames |
